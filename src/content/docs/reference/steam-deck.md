# Halloween: The Game Steam Deck — Compatibility, Easy Anti-Cheat & Launch Status

Confirmed

- Easy Anti-Cheat middleware is listed for the PC build in public secondary sources (PCGamingWiki) and the Steam storefront lists PC requirements such as Windows 11 64‑bit, 16 GB RAM minimum (32 GB recommended), GTX 1660 or equivalent minimum GPU, SSD/NVMe, and ~45 GB storage. The Steam page also lists full controller support for the PC release. (Sources: Steam store, PCGamingWiki)

- Steam Deck: there is no hands‑on or official Valve/IllFonic confirmation of Steam Deck Verified/Playable status at the time of this research. Do not treat Steam Deck compatibility as confirmed. (See “Not Announced” below.)

What to check at launch (evidence‑backed checklist)

1) Steam store page and Steam Deck badge — official Verified/Playable/Unsupported badges will appear on the store page if Valve has validated the build. This is the primary quick check. (Confirmed: store page exists; Not Announced: Deck badge.)

2) Official IllFonic/Steam posts — watch IllFonic’s news and Steam announcements for any statements about Proton/EAC or official Deck support.

3) Community reports (ProtonDB, Reddit, Deck user videos) — hands‑on users will publish whether the title runs under SteamOS, what Proton version and launch options (if any) help, and whether EAC blocks launch. Treat early community reports as empirical but check the date and method (SteamOS vs Windows on Deck).

4) If you plan to run Windows on your Deck: the PC requirements officially list Windows 11 64‑bit as the supported OS. Installing Windows on Deck is a separate, user‑managed workflow and can avoid Proton/EAC mismatch issues, but it is not guaranteed and has tradeoffs (drivers, battery, updates). Only pursue this if you understand Windows‑on‑Deck implications.

5) Controller support: the Steam store lists full controller support for PC. That suggests controller mappings should exist, but how those mappings translate to Steam Deck hardware still needs hands‑on confirmation.
