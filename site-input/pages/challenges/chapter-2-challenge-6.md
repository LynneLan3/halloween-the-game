# Chapter 2 Challenge 6 — Complete the chapter without alerting anyone

## Quick Answer

Patch 1.0.2 fixed an issue where certain executions counted as alerting someone. The strongest currently supported attempt is to get Surprise on Eric, Tanya, and Rachel, avoid any red alert/detection icon during the run, finish the chapter completely, then check challenge registration. This specific fix does not prove every possible failure mode is eliminated; clean runs may still fail to register. Tier 3 Stalk, Hard mode, Normal mode, and any Slab/Rachel kill order are unproven/anecdotal — not requirements.

## Exact objective

- Chapter 2 Challenge 6 objective: Complete the chapter without alerting anyone.

## Best-supported clean attempt (safe bounded steps)

Follow these steps in order for the safest, most supported attempt pattern based on community reports:

1. Update to Patch 1.0.2 (or newer) before you start.
2. Start a fresh Chapter 2 attempt (do not carry over an already-alerted state).
3. Keep the run strictly no-alert: avoid anything that produces a visible red alert / detection icon.
4. Aim for Surprise on Eric, Tanya, and Rachel (get Surprise on each of these three special targets).
5. Finish the chapter completely — reach the chapter end and let the end-of-chapter results screen run as intended.
6. After the chapter completes, check the challenge list / reward state for Chapter 2 Challenge 6.
7. If the run looks clean but the challenge did not register, treat it as a likely tracking outlier (see Troubleshooting below).

## Troubleshooting when a clean run does not register

- If you see a visible alert / red icon at any point in the run: stop and restart a clean attempt. The Patch 1.0.2 fix addresses certain execution miscounts, not a genuinely visible alert.
- Always finish the chapter completely before checking registration. Do not check mid-chapter; the challenge tends to register (or fail to) only after chapter completion.
- If a run appears clean (Surprise on Eric, Tanya, and Rachel; no red alert; chapter finished) but the challenge still does not register, treat that result as a likely tracking outlier. Monitor official patch notes and community reports for future fixes rather than inventing hidden conditions locally.
