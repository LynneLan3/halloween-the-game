# Halloween: The Game PC System Requirements

**Confirmed:** Steam publishes the current PC system requirements for Halloween: The Game (App ID 3219630). Treat store text as the authoritative baseline until IllFonic posts changes in patch notes.

## Minimum requirements

| Spec | Requirement |
| --- | --- |
| OS | Windows 11 64-bit |
| CPU | Intel LGA 1200+ / AMD AM4+ |
| Memory | 16 GB RAM |
| GPU | NVIDIA GTX 1660+ / AMD RX 590+ / Intel Arc A770+ |
| Performance target | 1080p @ 30 fps (as listed on Steam) |
| API | DirectX 12 |
| Network | Broadband internet connection |
| Storage | 45 GB — **SSD / NVMe required** |

## Recommended requirements

| Spec | Requirement |

| CPU | Intel LGA 1700+ / AMD AM5+ |
| Memory | 32 GB RAM |
| GPU | NVIDIA RTX 3000 series / AMD RX 7000 series |
| Performance target | 4K @ 30 fps (as listed on Steam) |
| API | DirectX 12 |
